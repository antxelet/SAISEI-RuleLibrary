#   - dailyProfit (0 = no official positive daily lock encoded)
#   - dailyLoss (0 = no fixed DLL encoded)

# until the library schema adds account-option variants.

#
# NEWS verification:
#   - Lucid Flex: news trading allowed.
#   - Alpha: all Evaluations + Advanced Qualified unrestricted.
#     Zero/Standard/Direct Qualified: no order executions from 2 min before
#     through 2 min after relevant Forex Factory High-impact events; holding allowed.
#   - Tradeify: news trading allowed without news-specific restrictions.
#   - LucidLive: no separate news restriction encoded in this V1 update.
#   - LucidDaily funded is still not encoded; official rule requires flat from
#     1 minute before through 1 minute after U.S. High-impact USD news.
#
# L|profileId|version|verified|dailyProfit|dailyLoss
# LI|profileId|instrument|max|ALLOW/BLOCK
# LN|profileId|verified|ALLOW/BLOCK_EXEC|impact|beforeMin|afterMin|AUTO-or-currencies
#
# NEWS semantics:
#   ALLOW      = no mandatory prop news window encoded.
#   BLOCK_EXEC = SAISEI must block/cancel its NEW ENTRY orders in the encoded window.
#                Holding an existing position is allowed unless a future mode says otherwise.
#   AUTO currencies = currencies relevant to the traded instrument (e.g. NQ -> USD).
